# Netty 实时聊天项目 (截至 2025-09-28)

## 项目概述

本项目是一个基于 Java 和 Netty 实现的、功能逐步完善的实时聊天应用后端。其架构设计参考了网络游戏服务器的核心理念，旨在为更复杂的实时应用（如网络游戏）奠定坚实的技术基础。

### 当前已实现功能

- 基于 WebSocket 的实时、双向通信。
- 使用 Protocol Buffers 定义的强类型、可扩展的通信协议。
- 支持用户名/密码认证的真实用户系统（新用户自动注册）。
- 支持创建房间、加入房间和在房间内进行消息广播（群聊）。
- 所有聊天消息持久化存储到内存数据库。
- 一个用于功能测试的交互式命令行客户端。

### 核心技术栈

- 开发语言: Java 21
- 核心网络框架: Netty 4.1.x
- 通信协议: WebSocket + Protocol Buffers 3.x
- 数据库: H2 (内存数据库，易于切换至 MySQL/PostgreSQL)
- 辅助工具: Lombok, SLF4J, Maven, BCrypt

### 后续可扩展方向
基于当前稳固的架构，未来可以向以下方向扩展：
- 完善房间功能：实现离开/解散房间、房间列表、房间内成员列表等。
- 拉取历史消息：为客户端提供查询和展示历史聊天记录的功能。
- 支持富媒体：支持图片、文件等消息类型，需要集成对象存储服务。
- 分布式架构：引入 Redis 进行分布式会话管理，使服务器可以水平扩展。
- 构建图形化客户端：使用 JavaFX, Swing 或前端框架（Vue, React）开发真正的图形界面客户端。
